01 · Gambaran Umum

Apa yang Akan Dihubungkan.

COSMIC CMS memakai Measurement ID untuk mencatat aktivitas halaman publik dan Service Account untuk membaca laporan secara aman dari dashboard.

Pengunjung Website→GA4→Data API→Dashboard CMS
KomponenFungsi
Measurement IDMengirim page view dan event. Format: G-XXXXXXXXXX.
Property IDNomor properti yang dibaca laporan dashboard.
Service Account JSONKredensial server dengan akses Viewer.
CacheMenyimpan laporan 15–120 menit agar hosting tetap ringan.
Privasi: CMS hanya mengambil data agregat. Private key disimpan terenkripsi dan tidak dikirim kembali ke browser.

Yang perlu disiapkan

  • Akun Google pengelola Analytics dan Google Cloud.
  • Akses Super Admin COSMIC CMS.
  • Akses terminal hosting untuk migrasi dan cron.

02 · Membuat Properti

Buat Properti GA4.

  1. Buka analytics.google.com dan masuk menggunakan akun Google.
  2. Buka Admin → Create Property.
  3. Isi nama COSMIC Website, zona waktu Indonesia, dan mata uang.
  4. Pilih platform Web, isi URL production dan nama stream.
  5. Aktifkan Enhanced Measurement lalu buat stream.
  6. Salin Measurement ID yang diawali G-.
  7. Buka Admin → Property Settings → Property Details dan salin Property ID yang hanya berisi angka.
Jangan keliru: Measurement ID berbeda dengan Property ID. Keduanya diperlukan.
3
03 · Google Cloud

Aktifkan Data API.

  1. Buka console.cloud.google.com dan buat project COSMIC Analytics.
  2. Buka APIs & Services → Library.
  3. Cari Google Analytics Data API, lalu klik Enable.
  4. Buka IAM & Admin → Service Accounts.
  5. Buat Service Account bernama cosmic-ga4-reader. Role Google Cloud tambahan tidak diperlukan.
  6. Buka Service Account → Keys → Add Key → Create new key.
  7. Pilih JSON, unduh, lalu simpan di tempat aman.
Rahasia: jangan unggah file JSON ke GitHub, Media Library, folder public, email publik, atau grup pesan.
4
04 · Beri Akses

Hubungkan Service Account.

  1. Buka file JSON dan salin nilai client_email.
  2. Kembali ke Google Analytics.
  3. Buka Admin → Property Access Management.
  4. Tambahkan alamat email Service Account.
  5. Pilih role Viewer. Jangan berikan Administrator.
  6. Simpan dan tunggu beberapa menit sampai izin aktif.
Akses minimum: Viewer cukup untuk membaca laporan dan tidak dapat mengubah properti.
5
05 · Dashboard COSMIC

Isi Konfigurasi GA4.

  1. Login sebagai Super Admin.
  2. Buka Pengaturan Website → Integrasi.
  3. Centang Aktifkan Google Analytics.
  4. Isi Measurement ID dan Property ID.
  5. Pilih cache 30 menit.
  6. Unggah file Service Account JSON.
  7. Klik Simpan Konfigurasi.
  8. Klik Uji Koneksi.
Berhasil: status menjadi “Terhubung”. Ringkasan muncul di dashboard dan laporan lengkap tersedia di Statistik Pengunjung.
Properti baru: data membutuhkan waktu untuk terkumpul. Angka nol pada beberapa jam pertama masih normal.

06 · Deployment

Migrasi & Scheduler.

Setelah source terbaru berada di hosting, jalankan:

cd /home/USERNAME/cms-cosmic
/opt/alt/php84/usr/bin/php artisan migrate --force
/opt/alt/php84/usr/bin/php artisan optimize:clear
/opt/alt/php84/usr/bin/php artisan optimize

Cron job setiap menit

* * * * * cd /home/USERNAME/cms-cosmic && /opt/alt/php84/usr/bin/php artisan schedule:run >> /home/USERNAME/cms-cosmic/storage/logs/scheduler.log 2>&1

Sesuaikan USERNAME, folder aplikasi, dan path PHP berdasarkan hosting.

Verifikasi

/opt/alt/php84/usr/bin/php artisan schedule:list
/opt/alt/php84/usr/bin/php artisan analytics:sync
Tidak perlu queue worker: integrasi memakai cache dan scheduler Laravel sehingga cocok untuk shared hosting.

07 · Pengujian

Pastikan Berjalan.

  1. Buka landing page dalam mode incognito.
  2. Buka Beranda, Jadwal, Detail Pertandingan, dan satu Berita.
  3. Di GA4 buka Reports → Realtime dan pastikan ada pengguna aktif.
  4. Buka dashboard COSMIC dan periksa kartu Statistik Pengunjung.
  5. Klik kartu untuk melihat halaman, sumber trafik, perangkat, lokasi, dan event.
  6. Gunakan Perbarui Data bila diperlukan. Aksi ini dibatasi agar API tetap ringan.
EventArti
page_viewPerpindahan halaman publik.
view_schedule / view_matchMembuka jadwal atau pertandingan.
view_newsMembuka detail berita.
play_our_storyMemutar video Our Story.
share_match / share_articleMembagikan konten.

08 · Troubleshooting

Jika Data Tidak Muncul.

MasalahPemeriksaan
Uji koneksi gagalPeriksa Property ID, Data API, dan akses Viewer Service Account.
Realtime kosongPeriksa Measurement ID dan nonaktifkan ad blocker saat pengujian.
Dashboard menampilkan data lamaTunggu cache 30 menit atau gunakan Perbarui Data.
Scheduler tidak memperbaruiJalankan analytics:sync dan periksa laravel.log serta scheduler.log.
403 Permission DeniedService Account belum menjadi Viewer pada properti yang benar.
Credential invalidBuat key JSON baru dan hapus key lama dari Google Cloud.
Jangan kirim private_key: informasi yang aman dibagikan hanya Measurement ID, Property ID, dan pesan error tanpa kredensial.

Checklist selesai

  • Status GA4 Terhubung.
  • Realtime mendeteksi kunjungan.
  • Permission halaman statistik bekerja.
  • Cron Laravel berjalan setiap menit.
  • File JSON tidak berada di public atau Git.
