01 · Tujuan & Scope

Cerita di Balik Skor.

Modul Match Events menjelaskan bagaimana sebuah skor dan jalannya pertandingan terbentuk. Setiap event terikat pada pertandingan, klub, menit kejadian, serta pemain yang relevan.

Keputusan utama: event tidak menjadi sumber skor. Skor final tetap berada pada record pertandingan; sistem membandingkan total gol event dengan skor sebagai pemeriksaan rekonsiliasi.

Goal & Assist

Pencetak gol, assist opsional, tipe gol, menit, dan injury time.

Discipline

Kartu kuning, kartu merah, dan kartu kuning kedua.

Substitution

Pemain keluar dan pemain masuk dalam satu event atomik.

Timeline

Urutan kronologis yang dapat ditampilkan pada detail pertandingan.

04 · Business Rules

Timeline yang Valid.

  • Event hanya dapat dibuat untuk pertandingan yang belum dihapus.
  • Club event wajib home atau away pada pertandingan tersebut.
  • Pemain harus berasal dari klub event dan, jika lineup tersedia, harus terdaftar dalam lineup laga.
  • Gol normal/penalti memerlukan scorer; assist opsional dan tidak boleh pemain yang sama.
  • Own goal mencatat pemain pelaku dari klub lawan, tetapi goal credit diberikan ke club_id.
  • Substitution memerlukan player out dan player in yang berbeda dari klub sama.
  • Minute tidak negatif; added minute tidak boleh ada tanpa minute.
  • Event hasil pertandingan completed hanya dapat dikoreksi oleh permission khusus dengan alasan wajib.
  • Event yang dihapus memakai soft delete agar histori dan audit tidak hilang.

Agregasi: V1 menghitung statistik dari event melalui query/service dan cache. Tabel snapshot statistik baru dibuat kemudian jika volume data memerlukannya.

Aturan Statistik

  • Hanya event pada match completed dan public yang masuk statistik publik.
  • Own goal tidak menjadi gol pemain untuk leaderboard.
  • Event yang dihapus atau private tidak dihitung.
  • Perubahan event membersihkan cache match, player, league, dan homepage.
  • Filter statistik mengikuti season/competition, bukan hanya tanggal kalender.

08 · Migration & Acceptance

Implementasi yang Terukur.

Schema + Permission→Domain Service→Admin Timeline→Public + Stats

Seed Awal

Pertandingan selesai yang sudah tersedia akan memperoleh event demo yang konsisten dengan skor. Nama pemain hanya dipakai jika record pemain dan lineup valid; jika belum, event tetap tidak dipaksakan.

Kriteria Penerimaan

  • Admin dapat menambah, mengedit, menghapus, mengurutkan, dan mempublikasikan event.
  • Gol mendukung scorer, assist, penalty, own goal, minute, dan added minute.
  • Kartu serta substitution memakai pemain dan klub yang valid.
  • Event completed membutuhkan permission koreksi dan alasan.
  • Rekonsiliasi mendeteksi selisih event gol terhadap skor pertandingan.
  • Timeline muncul pada detail pertandingan dan panel hasil.
  • Statistik pemain dan Top Players berasal dari event published.
  • Cache publik dibersihkan setelah mutasi.
  • Semua mutasi penting tercatat dalam audit.
  • UI admin responsif dan konsisten dengan COSMIC CMS.
  • Feature test meliputi permission, validasi aktor, event type, correction, reconciliation, public payload, statistics, audit, dan soft delete.
