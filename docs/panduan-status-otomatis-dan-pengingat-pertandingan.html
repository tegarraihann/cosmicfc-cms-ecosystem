COSMIC CMS · PANDUAN DEPLOYMENT

Status Otomatis dan Pengingat Pertandingan

Panduan nonteknis untuk menyiapkan cron, Telegram, email, serta memeriksa alur pertandingan dari terjadwal sampai selesai.

Versi: 8 November 2026

1. Cara kerja sistem

WaktuTindakan otomatis
Sebelum kick-offStatus tetap Terjadwal.
Saat kick-offStatus berubah menjadi Sedang berlangsung dan skor otomatis disinkronkan dari kejadian pertandingan.
15 menit sebelum perkiraan selesaiSistem mengirim pengingat Telegram dan email superadmin jika tidak ada admin yang sedang aktif mengelola pertandingan.
Saat perkiraan selesaiStatus berubah menjadi Selesai. Skor disinkronkan, cache publik dibersihkan, audit disimpan, dan klasemen kompetitif dihitung ulang.
Perkiraan selesai dihitung dari waktu kick-off + durasi pertandingan. Nilai awal durasi adalah 120 menit dan dapat diubah pada form pertandingan.

2. Jalankan migrasi dan cache konfigurasi

Dari Terminal cPanel, masuk ke folder aplikasi lalu jalankan:

cd /home/USERNAME/cms-cosmic
/opt/alt/php84/usr/bin/php artisan migrate --force
/opt/alt/php84/usr/bin/php artisan optimize:clear
/opt/alt/php84/usr/bin/php artisan config:cache
/opt/alt/php84/usr/bin/php artisan route:cache
/opt/alt/php84/usr/bin/php artisan view:cache

Ganti USERNAME dengan username hosting. Jangan menjalankan migrate:fresh karena perintah itu menghapus data.

3. Konfigurasi cron cPanel

Buat satu cron dengan frekuensi Once Per Minute:

cd /home/USERNAME/cms-cosmic && /opt/alt/php84/usr/bin/php artisan schedule:run >> /home/USERNAME/cms-cosmic/storage/logs/scheduler.log 2>&1

Nama command aplikasi tetap matches:sync-statuses. Tidak perlu membuat cron kedua karena Laravel scheduler akan memanggilnya setiap menit.

4. Menyiapkan bot Telegram

  1. Buka Telegram dan cari akun resmi @BotFather.
  2. Kirim /newbot, lalu ikuti petunjuk nama dan username bot.
  3. Simpan token yang diberikan BotFather. Token adalah rahasia dan hanya boleh berada di file .env server.
  4. Buat grup operasional, masukkan bot, lalu kirim satu pesan ke grup.
  5. Dapatkan chat ID melalui endpoint getUpdates atau utilitas Telegram tepercaya. Chat ID grup biasanya diawali tanda minus.

Tambahkan ke .env:

TELEGRAM_BOT_TOKEN=isi_token_dari_botfather
TELEGRAM_CHAT_ID=-100xxxxxxxxxx
MATCH_REMINDER_LEAD_MINUTES=15
MATCH_ADMIN_PRESENCE_TTL_MINUTES=3
Keamanan: jangan menaruh token di JavaScript, GitHub, screenshot, atau isi pesan. Jika bocor, gunakan BotFather untuk mencabut dan membuat token baru.

5. Konfigurasi email

Sistem memakai SMTP Laravel yang sama dengan verifikasi email. Pastikan bagian berikut sudah benar di .env:

MAIL_MAILER=smtp
MAIL_HOST=mail.domainanda.com
MAIL_PORT=465
MAIL_SCHEME=smtps
MAIL_USERNAME=notifikasi@domainanda.com
MAIL_PASSWORD=password_email
MAIL_FROM_ADDRESS=notifikasi@domainanda.com
MAIL_FROM_NAME="COSMIC CMS"

Email dikirim kepada akun superadmin yang aktif. Setelah mengubah .env, ulangi php artisan config:cache.

6. Pengujian setelah deployment

  1. Jalankan /opt/alt/php84/usr/bin/php artisan schedule:list. Pastikan matches:sync-statuses tampil setiap menit.
  2. Jalankan manual: /opt/alt/php84/usr/bin/php artisan matches:sync-statuses -vvv.
  3. Buat pertandingan uji dengan kick-off beberapa menit ke depan dan durasi minimal 30 menit.
  4. Pastikan status berubah menjadi Sedang berlangsung saat kick-off.
  5. Pastikan pengingat hanya terkirim satu kali per kanal.
  6. Buka modal kejadian/hasil sebagai admin. Selama aktif, pengingat eksternal ditunda.
  7. Setelah perkiraan selesai, pastikan status Selesai, skor publik benar, audit tersedia, dan klasemen diperbarui bila pertandingan dihitung.

7. Pemeriksaan log

tail -n 100 storage/logs/scheduler.log
tail -n 100 storage/logs/laravel.log

Riwayat pengiriman juga tersimpan di tabel match_notification_logs. Sistem menggunakan kunci idempoten agar cron setiap menit tidak menggandakan pesan.
