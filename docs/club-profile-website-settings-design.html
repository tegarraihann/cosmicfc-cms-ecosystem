01 · Tujuan

Satu Identitas, Semua Halaman.

Profil Klub & Website menyimpan informasi global yang tidak seharusnya ditulis ulang pada setiap section: identitas, alamat, kontak, social media, branding, SEO, dan pengaturan umum.

Keputusan utama: section tetap mengelola copy editorialnya sendiri, tetapi mengambil identitas global seperti nama COSMIC, logo, kota, tahun berdiri, kontak, dan social link dari modul ini.

Konsistensi

Mengubah lokasi atau Instagram satu kali memperbarui seluruh konsumen.

Kontrol

Draft, preview, publish, permission, dan audit mengikuti pola CMS.

Brand Safety

Logo, warna, dan slogan memiliki format dan validasi yang dibatasi.

SEO

Metadata default terpusat dengan kemungkinan override per halaman.

Data Founder

Profil klub hanya menyimpan referensi founder utama (founder_staff_id) ke modul Staff & Officials. Nama dan foto tidak diduplikasi. Jika modul Staff belum tersedia, dapat digunakan fallback teks sementara.

Warna website tidak menerima CSS bebas. Admin memilih token brand yang tervalidasi agar kontras dan tampilan tetap konsisten.

Struktur Penyimpanan.

club_profiles ├── id ├── club_name, short_name ├── tagline, short_description ├── founded_at ├── city, country, home_base, address ├── map_url ├── email, phone, whatsapp ├── contact_person ├── logo_media_id, alternate_logo_media_id ├── favicon_media_id, share_image_media_id ├── founder_staff_id // nullable ├── status // draft | published ├── version ├── created_by, published_by ├── published_at └── timestamps club_social_links ├── club_profile_id ├── platform // instagram, tiktok, youtube... ├── url, handle ├── is_active, sort_order └── timestamps website_settings ├── key // seo.default_title, site.timezone... ├── value // JSON ├── group └── timestamps

Implementasi boleh memakai dua record profile (draft/published) atau version table. Yang terpenting: publish atomik dan draft tidak bocor ke publik.

07 · Migration

Data Awal & Fallback.

Nilai yang sekarang tersebar di Vue, footer, dan section harus dikumpulkan sebagai default resmi sebelum modul dipakai.

Audit Hardcoded Data→Normalisasi→Seed Published→Clone Draft→Hubungkan Konsumen

Data Awal yang Perlu Dikumpulkan

  • COSMIC / nama resmi klub.
  • Pekanbaru, Indonesia dan home base.
  • Tahun/tanggal resmi berdiri.
  • Logo dan variasinya.
  • Slogan “Good People. Better Football.”
  • Email, WhatsApp, dan contact person resmi.
  • URL social media resmi.
  • Founder sebagai referensi Staff & Officials.
  • Default SEO title, description, dan share image.
Fallback: jika profile record belum tersedia, frontend menggunakan config bawaan. Setelah migrasi berhasil, database menjadi sumber utama dan fallback hanya untuk kondisi darurat.

08 · Acceptance

Kriteria Penerimaan.

  • Editor pertama kali dibuka menampilkan data COSMIC yang saat ini tampil di website.
  • Mengubah kota pada draft tidak memengaruhi publik sebelum publish.
  • Preview menampilkan dampak pada Beranda, Tim, dan Footer.
  • Publish memperbarui shared site props dan membersihkan cache.
  • Navbar dan footer tidak lagi menyimpan identitas klub secara hardcoded.
  • Social link nonaktif tidak dirender.
  • Logo dipilih dari Media Library dan mempunyai alt text.
  • Role tanpa permission tidak dapat mengakses endpoint mutasi.
  • Audit menyimpan pengguna, waktu, versi, dan nilai sebelum/sesudah.
  • Seeder tidak menimpa data yang sudah dikelola admin.
